# QR-System

A mobile application for school attendance and student management system built with React Native and Expo. This app enables teachers and administrators to efficiently track student attendance, monitor student behavior, and manage student records using QR code scanning technology.

## Features

### Authentication & User Management
- Role-based access control (Parent and Teacher roles)
- Secure login system
- Role-based with customized views for different user types

### Attendance Management
- QR code-based student attendance tracking
- Real-time attendance recording
- Attendance status monitoring (Present, Absent, Late, etc.)
- Attendance history and reporting

### Student Management
- Comprehensive student profile management
- Student details and information tracking
- CRUD operations for student records
- Student data integration with backend system

### Behavior & Discipline Tracking
- Discipline record management
- Behavior points system
- Character assessment (Sahsiah) tracking
- Student conduct monitoring

### Leaderboard & Gamification
- Student performance leaderboard
- Points and rewards system
- Motivational features for students

### Localization
- Multi-language support
- Language switching capabilities
- Localized user interface

### Technical Features
- Built with React Native via Expo for cross-platform mobile development
- Backend integration with Django REST API
- Responsive and mobile-first design

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

In the output, you'll find options to open the app in a

- [development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go), a limited sandbox for trying out app development with Expo

You can start developing by editing the files inside the **app** directory. This project uses [file-based routing](https://docs.expo.dev/router/introduction).
